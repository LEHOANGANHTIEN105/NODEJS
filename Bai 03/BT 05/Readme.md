# BÀI 05 – Tìm kiếm, cập nhật và sắp xếp MongoDB

## Các bước thực hiện

### Bước 1: Mở Terminal tại thư mục `BT 05`.

Sử dụng lệnh:

cd "D:\CĐ - CNTT18A\Bài 3 - Bài Tập 1\Node JS\Bai 03\BT 05"

### Bước 2: Cài đặt thư viện MongoDB

Mở Terminal tại thư mục Bt05 và chạy lệnh:

npm install mongodb

### Bước 3: Kiểm tra thư viện
Sử dụng lệnh:

npm list mongodb

Kết quả: mongodb@7.9.0

### Bước 4: Chạy chương trình
Sử dụng lệnh:

node bai05.js

### Bước 5: Thực hiện các thao tác
- Kết nối MongoDB.
- Truy vấn sinh viên có điểm >= 7.
- Sắp xếp điểm theo thứ tự giảm dần.
- Cập nhật điểm sinh viên SV001 thành 9.5.
- Hiển thị lại thông tin sinh viên sau cập nhật.
