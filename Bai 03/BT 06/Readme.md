# BÀI TẬP 06 – Xây dựng Module tính kết quả học tập

## Các bước thực hiện

### Bước 1: Tạo file xulyDiem.js

Xây dựng hai hàm:
- tinhDiemTB(): Tính điểm trung bình 3 môn.
- xepLoai(): Xếp loại học tập.

Sử dụng module.exports để xuất hai hàm.

### Bước 2: Tạo file bai06.js

- Sử dụng require('./xulyDiem') để gọi module.
- Tạo dữ liệu 3 sinh viên.
- Tính điểm trung bình và xếp loại.
- Hiển thị họ tên, điểm trung bình và xếp loại trên Terminal.

### Bước 3: Chạy chương trình

Mở Terminal tại thư mục Bt06 và nhập lệnh:

-- cd "D:\CĐ - CNTT18A\Bài 3 - Bài Tập 1\Node JS\Bai 03\BT 06"

-- node bai06.js
